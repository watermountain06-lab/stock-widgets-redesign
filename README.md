# 프로젝트 목표

1. prism-provenance.com의 시각적 특징을 참고한 카드형 UI: 밝은 배경, 은은한 그라데이션, 둥근 카드와 부드러운 그림자.
2. 데스크톱·태블릿·모바일에서 읽기 편한 반응형 CSS.

## 현재 적용 범위

- 메인 종목 목록: 1000px 초과 3열, 601~1000px 2열, 600px 이하 1열.
- 시장 지표, 요약 카드, 탐색 탭과 검색 영역의 반응형 배치.
- 순위·업종·등락률 보기, 종목 검색, 브라우저에 저장되는 즐겨찾기.
- 상세 분석 12개 페이지에 공통 헤더·밝은 카드 테마·모바일 배치 적용 (`detail-theme.css`). 기존 분석 내용은 최신 자료로 검증하지 않았으며 보관 자료로 표시합니다.
- `today.html`: PRISM 한국어 Today 페이지를 참고한 날짜 탐색·간결한 시세 카드·이전/다음 종목 탐색. 스타일은 `today.css`, 예시 목록과 동작은 `today.js`에서 관리합니다.

`index.html`을 브라우저에서 열거나 정적 웹 서버로 실행합니다. 메인 스타일은 `styles.css`에서 관리합니다.

현재 시장 지표와 종목 시세는 예시 데이터입니다. 매력도별 보기는 준비 중입니다.

## 데이터와 탐색

- `stock-data.js`: Home/Today 공통 종목 및 날짜 목록. 날짜 목록은 예시 편성입니다.
- `navigation.js`: 좌우 방향키 및 터치 스와이프. 카드 영역에 포커스한 뒤 방향키를 사용합니다. 링크와 입력창에서는 기본 동작을 유지합니다.
- Today의 날짜/카드 선택은 URL에 저장되어 새로고침, 뒤로가기, 직접 링크에 반영됩니다.
- 애니메이션은 사용자 요청에 따라 0.3초이며 모션 감소 설정과 관계없이 실행됩니다.

## 실제 시세 연결 준비 (아직 미연결)

Twelve Data 계정의 API 키와 공개 표시 권한이 필요합니다. 키는 환경변수 `TWELVE_DATA_API_KEY`로만 전달하고 브라우저 파일이나 저장소에 넣지 않습니다.

`node scripts/update-quotes.mjs`를 실행하면 검증된 응답을 모아 `quotes-snapshot.json`을 생성합니다. 중간 실패 시 기존 파일을 보존합니다. Home/Today는 이 파일을 읽고 출처·시세 시각·파일 갱신 시각을 표시합니다. 지연 시간은 확정되지 않아 미확인으로 표시합니다. API를 실제 호출한 검증은 키가 없어 수행하지 못했습니다.

SPCX는 심볼/상장 검증 전이므로 수집하지 않습니다. 시가총액·매크로 지표·상세 분석은 이 시세 갱신 대상이 아니며 예시 또는 보관 자료입니다. 자동 갱신 작업은 아직 설정하지 않았습니다.

문서: https://twelvedata.com/docs/market-data/quote

## 간결한 Home / Today

- 오늘의 종목: 전체, 5% 이상 상승·하락, 저평가·초저평가 분류. 등락률 조건과 개수는 등록 목록에서 계산하며 최대 6개를 표시합니다. 상장 미확인 SPCX는 이 영역에서 제외합니다.
- 가치 분류는 평가 데이터 미연결 상태로 표시합니다. 검증된 평가 기준을 마련한 뒤 valuation 필드에 undervalued 또는 deep-value를 제공해야 합니다.
- Today: 시세 요약, 날짜·종목별 로컬 체크리스트와 개인 토론 메모. 메모는 브라우저에만 저장되며 다른 사용자와 공유되지 않습니다.
- 뉴스·영상: 선택 종목의 Google 뉴스와 YouTube 검색 링크. API 자동 수집은 미연결입니다. 연결 시 서버에서 키를 관리하고 출처·게시 시각·갱신 시각을 함께 제공해야 합니다.
- 밝고 차분한 배경, 작은 분석대상 카드. root와 dist 파일을 함께 반영했습니다.
- 검증: 1280px/390px 화면, 분류/빈 상태, 날짜별 종목 탐색, 체크리스트·메모 저장, JavaScript 오류 및 가로 넘침 확인.

## UI 업데이트
- 오늘의 종목: 상승·하락·저평가·초저평가 네 분류를 5초 간격으로 전환. 일시정지와 포커스/호버 중 정지 지원.
- 순위별 카드는 유지하고 업종·등락률·매력도는 표로 표시. 매력도는 미평가로 표시.
- 시장 지표 기본 펼침, 시스템 light/dark 자동 반영, Today 실제 날짜 및 종목별 요약 공간 추가.
